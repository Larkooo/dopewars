# Contracts

Dope Wars is built with [Dojo](https://dojoengine.org), a framework for onchain games and applications on Starknet. All contracts are written in **Cairo** under the `dopewars_v0` namespace.

## Stack

- **Starknet L2** — Settlement and execution layer
- **Dojo 1.7.1** (Cairo 2.12.2) — Game framework (world/system/model pattern)
- **Cartridge VRF** — Provable onchain randomness for encounters, season generation, and market variations
- **Torii** — Indexer with GraphQL subscriptions for real-time frontend state

## Contract systems

#### Game

Core game logic: creation, travel, trading, shopping, and game end.

| System | Purpose |
|--------|---------|
| `game` | Create game, travel, end game |
| `decide` | Handle encounter decisions (Fight/Run/Pay) |

#### Economy

Season management, scoring, and rewards distribution.

| System | Purpose |
|--------|---------|
| `laundromat` | Score registration, payout processing, reward claims |
| `ryo` | Season configuration, admin controls, pause/unpause |

#### Configuration

Game parameters, drug pricing, encounter stats, and equipment.

| System | Purpose |
|--------|---------|
| `config` | Emit item configs, initialize drug/encounter/location settings |
